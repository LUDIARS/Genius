# ViewerからGeniusを開くと404になる

- Date: 2026-09-10
- Status: fixed in working tree
- Area: Viewer catalog entry
- Severity: UI cannot be opened from the service menu

## Summary

Viewerの掲載設定でentry_pathを/としたが、既存UIは/ui/で配信される。

## Evidence

反映時、両Viewer Originを付けた/viewer/apps/genius/要求がJSONの404を返した。
src/api/routes/ui.tsは/uiを/ui/へ転送し、/ui/*からUIを配信する。

## Cause

入口設定の誤り。Origin許可の反映後もルートURLには画面がない。

## Fix Requirements

entry_pathを/ui/にする。既存アプリのルートやAPI、許可Originは変更しない。

## Verification

ソースとの照合とgit diff --checkのみ。修正後の本体反映とHTTP/画面確認は別途行う。
